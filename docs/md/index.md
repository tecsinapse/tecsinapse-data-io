# Tecsinapse Data IO

Biblioteca Java de leitura e escrita de planilhas e tabelas (Excel, CSV e afins).

**System:** tecsinapse-data-io · **Tipo:** library · **Owner:** kaizen

## Propósito

Oferecer API comum para importar e exportar dados tabulares nos produtos TecSinapse, com conversores tipados e extensão para Java Time, Joda e JSF.
